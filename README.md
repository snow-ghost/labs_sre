# Практикумы по SRE

Скрипты и инструкции для семинаров по надежности и эксплуатации систем. Каждый семинар находится в отдельном каталоге `seminars/`. Сейчас опубликован семинар 3.

| Семинар | Тема | Материалы |
|---|---|---|
| 3 | Производительность дисков: fio, iostat и LVM | [Инструкция и скрипты](seminars/03-storage/README.md) |

## Начало работы

```bash
git clone https://github.com/snow-ghost/labs_sre.git
cd labs_sre/seminars/03-storage
bash check.sh
bash demo.sh
```

Перед запуском установите зависимости из [инструкции семинара](seminars/03-storage/README.md#подготовка-компьютера). Стенд рассчитан на Ubuntu 24.04 x86_64, Python 3.12 и доступ к KVM. Для самой демонстрации `sudo` не нужен.

Внутри учебной ВМ команда `show 1` показывает исходник этапа, а `run 1` выполняет его. Подготовка, порядок этапов и привязка к слайдам описаны в инструкции. Презентация используется на занятии отдельно; здесь сохранены номера ее слайдов.

## Добавление семинаров

Новые материалы размещаются в отдельных каталогах, например `seminars/04-network/`. У каждого семинара должны быть инструкция запуска, требования к окружению, скрипты и описание результата. После добавления семинара обновляется таблица выше.

Каталоги `runs/`, `cache/`, образы ВМ и локальные файлы `ПРОВЕРЕНО.txt` исключены из Git. Результаты запусков остаются на компьютере участника.
